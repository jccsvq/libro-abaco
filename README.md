libro-abaco
---
Este repositorio contiene la trascripción y revisión del wikilibro [El Ábaco Oriental](https://es.wikibooks.org/wiki/%C3%81baco_Oriental) (y su [version PDF](https://upload.wikimedia.org/wikipedia/commons/6/69/%C3%81baco_Oriental-Wikilibro.pdf)) a [TiddlyWiki5](https://tiddlywiki.com/).

La finalidad es doble:

1. Disponer de un sistema más sencillo para proceder a correcciones, ampliaciones, etc. por parte del autor. Por tanto, este proyecto es la continuación de los citados trabajos anteriores.
2. Permitir que el lector pueda descargarse si lo desea una  copia local donde añadir sus propias notas, correcciones, ampliaciones o lo que quiera, ya que la copia descargada contendrá todo el software necesario para hacerlo, incluida la posibilidad de añadir expresiones matemáticas en formato LaTeX y, haciendo uso de los sencillos scripts en AWK suministrados, codificar fácilmente diagramas de un variedad de ábacos.


This repository contains the transcription and revision of the Wikibooks [Using an Abacus](https://en.wikibooks.org/wiki/Using_an_Abacus) and [Traditional Abacus and Bead Arithmetic](https://en.wikibooks.org/wiki/Traditional_Abacus_and_Bead_Arithmetic)(and its [PDF version](http://totton.idirect.com/soroban/Jes%C3%BAs%20Cabrera/The%20Eastern%20Abacus.pdf)) to [TiddlyWiki5](https://tiddlywiki.com/).

The purpose is twofold:

1. To provide a simpler system for the author to make corrections, additions, etc. This project is therefore a continuation of the aforementioned previous work.
2. To allow the reader to download a local copy if they wish, in which they can add their own notes, corrections, extensions or whatever they wish, since the downloaded copy will contain all the necessary software to do so, including the possibility of adding mathematical expressions in LaTeX format and, using the simple AWK scripts supplied, easily coding diagrams of a variety of abacuses.
